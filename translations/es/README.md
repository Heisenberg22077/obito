## Objetivo

Esta hoja de ruta convierte syllabus universitarios de alta calidad y recursos educativos abiertos en un currículo completo con prerrequisitos claros. Está diseñada para ayudarte a:

- Construir fundamentos sólidos en matemáticas, estadística y programación
- Aprender machine learning clásico antes de saltar a modelos fronterizos
- Implementar sistemas reales con ingeniería de datos, MLOps, RAG, agentes y evaluación
- Terminar con un portafolio de proyectos capstone listos para mostrar

> **Compromiso esperado:** aproximadamente 24–36 meses a 20–25 horas por semana para la ruta completa. No necesitas completar todos los módulos para roles específicos.

## Elige tu Track

| Track | Módulos recomendados | Resultado de portafolio |
|---|---|---|
| **Data Analyst** | M1 → M6 → M7 → M8a → M25 → M26 | Análisis reproducible, dashboard y memo para stakeholders |
| **Data Scientist** | M1–M7 → M9–M14 → M25 → M26 | Modelo validado más evaluación causal o experimental |
| **Data Engineer** | M1 → M4 → M7 → M8a → M8b → M24 → M26 | Plataforma de datos batch/streaming testeada con observabilidad |
| **ML Engineer** | M1–M12 → M15–M17 → M24 → M26 | Modelo servido detrás de API con CI, monitoreo y SLOs |
| **AI Engineer** | M1 → M8a → M15–M18 → M21–M24 → M26 | Sistema RAG o agente evaluado con trazas y guardrails |
